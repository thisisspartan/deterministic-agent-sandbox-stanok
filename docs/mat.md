# mat — матричные операции 2x2 (TASK-STANOK-CC-016)

Модуль `src/mat.js` — чистые детерминированные функции над матрицами 2x2.
Без внешних зависимостей, без side effects.

## Формат матрицы

Матрица — объект `{ a, b, c, d }`, где строки: `[a, b]`, `[c, d]`:

```
[ a  b ]
[ c  d ]
```

Все компоненты — числа (NaN/не-число отклоняются).

## API

- `identity()` → `{a: 1, b: 0, c: 0, d: 1}` — единичная матрица (новый объект
  при каждом вызове).
- `mul(m, n)` → `{a, b, c, d}` — произведение `m * n`:
  - `a = m.a*n.a + m.b*n.c`
  - `b = m.a*n.b + m.b*n.d`
  - `c = m.c*n.a + m.d*n.c`
  - `d = m.c*n.b + m.d*n.d`
- `mulVec(m, v)` → `{x, y}` — умножение матрицы на вектор `{x, y}`:
  - `x = m.a*v.x + m.b*v.y`
  - `y = m.c*v.x + m.d*v.y`
- `det(m)` → `m.a*m.d - m.b*m.c` — определитель.
- `transpose(m)` → `{a: m.a, b: m.c, c: m.b, d: m.d}`.

## Примеры

```js
const { identity, mul, mulVec, det, transpose } = require('./src/mat.js');

identity();                                            // {a: 1, b: 0, c: 0, d: 1}
mul({a: 1, b: 2, c: 3, d: 4}, {a: 5, b: 6, c: 7, d: 8});
// {a: 19, b: 22, c: 43, d: 50}
mulVec({a: 1, b: 2, c: 3, d: 4}, {x: 5, y: 6});       // {x: 17, y: 39}
det({a: 1, b: 2, c: 3, d: 4});                         // -2
transpose({a: 1, b: 2, c: 3, d: 4});                   // {a: 1, b: 3, c: 2, d: 4}
```

Инварианты: `mul(identity(), m) === m`, `mulVec(identity(), v) === v`.

## Семантика ошибок

- Не-объектный аргумент (null/число/массив и т. п.) — `TypeError`, имя
  аргумента (`m`/`n`/`v`) в сообщении.
- Нечисловая (включая `NaN`) компонента — `TypeError` с именем компоненты
  (`"a"` / `"b"` / `"c"` / `"d"` для матриц, `"x"` / `"y"` для вектора)
  в сообщении.
- Функции не мутируют аргументы и всегда возвращают новые объекты/числа.
