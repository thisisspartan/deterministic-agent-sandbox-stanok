# fire — цветное пламя в консоли (tickets TASK-STANOK-CC-030/031/032)

Бесконечная анимация пламени в стиле камина: пламя — язык, широкий у
основания и сужающийся кверху; источник — центральная зона низа; пламя
«дышит» (медленная модуляция интенсивности); сверху летят искры (только
из центральной зоны). Пламя горит ВНУТРИ камина: статичная кирпичная
рамка по периметру и тёмный фон окна (ticket 032). Брёвен/дров внутри
НЕТ — только 2D-рамка. Работает вечно до выхода.

## Камин (ticket 032)

- **Рамка** — статична (не зависит от state/heat, детерминирована):
  символы кирпич/камень `▓ █ ▒`, цвета 236–238 (тёмно-серые, из диапазона
  палитры 236–239). Конструкция: подиум снизу (2 ряда кирпичей на всю
  ширину), перемычка сверху (2 ряда), боковые стойки (2 колонки слева и
  справа). При узких сетках (H≤4 или W≤8) толщина падает до 1 ряда/колонки.
- **Тёмный фон окна** — ячейки окна с heat=0 рендерятся цветом 234
  (дип-серый, диапазон 233–235), а не пустым пробелом: огонь горит «в
  темноте». Вне камина ничего не рисуется.
- **Брёвен/палок/дров внутри камина нет.**

## Запуск

```sh
node src/fire/main.js
```

- **TTY (интерактивно)**: raw mode, альтернативный экран (`\x1b[?1049h`),
  курсор скрыт; полный перерисовочный кадр каждые ~33 мс (~30 FPS).
- **Non-TTY** (pipe/CI): рендерятся 10 фиксированных кадров в stdout,
  `exit(0)` — программа не вешается без терминала.

## Управление (выход)

| Клавиша      | Действие                     |
|--------------|------------------------------|
| `q` / `Q`    | чистый выход                 |
| `ESC`        | чистый выход                 |
| `Ctrl+C`     | чистый выход (или SIGINT)    |

При остановке (любой причиной, включая ошибку) ВСЕГДА восстанавливается
терминал: курсор показывается (`\x1b[?25h`) и альтернативный экран
закрывается (`\x1b[?1049l`).

## Параметры

`createFire(opts)` / `attach(io, fire, opts)` (все необязательны):

| Параметр      | Дефолт          | Смысл                                   |
|---------------|-----------------|-----------------------------------------|
| `W`           | `80`            | ширина сетки (столбцов)                 |
| `H`           | `24`            | высота сетки (рядов)                    |
| `seed`        | `1`             | зерно PRNG (детерминизм)                |
| `rng`         | `mulberry32(seed)` | инжектируемый PRNG, функции `[0,1)`  |
| `decay`       | `0.88`          | затухание тепла вверх (0.85…0.92)       |
| `sparks`      | `16`            | число частиц-искр                       |
| `fpsMs`       | `33`            | период кадра UI (~30 FPS)               |

Детерминизм: один `seed` → идентичные кадры (тепло и искры) при
пошаговом прогоне; `opts.rng` позволяет заменить PRNG целиком.

## Физика (src/fire/fire.js)

- Сетка `W×H` температур `heat[y][x] ∈ [0..1]`, источник тепла — ЦЕНТРАЛЬНАЯ
  ЗОНА нижнего ряда (средние 50% ширины, `SOURCE_HALF = 0.25`): плавный
  косинусный профиль по X (1.0 в центре → 0 к краям зоны), вне зоны — 0;
  базовая температура ~1.0 с фликером (шум).
- Шаг симуляции снизу вверх:
  `heat[y][x] = avg(heat[y+1][x-1..x+1]) * decay * taper(y) + noise*sparkle`,
  `decay ≈ 0.85..0.92`.
- Сужение кверху (F2): `taper(y) = 1 - ((H-1-y)/H)^k * TAPER_MAX`
  (`TAPER_K = 2`, `TAPER_MAX = 0.6`) — верхние ряды заметно холоднее,
  пламя сужается кверху, как язык.
- Полыхание / «дыхание» (F3): низкочастотный синус
  `breath = 1 - AMP * (0.5 + 0.5*sin(2π·frame / PERIOD))`
  (`PERIOD = 60` кадров ≈ 2 с при 30 FPS, `AMP = 0.15`, т.е. ±15%)
  модулирует интенсивность источника; детерминировано счётчиком кадров —
  один seed → те же кадры.
- Искры: N частиц `{x, y, vy, life}` — поднимаются (`vy < 0`), затухают
  (`life` убывает), при `life <= 0` или вылете за верх возрождаются
  ТОЛЬКО в центральной зоне источника (x ∈ [W/4, 3W/4]); дрейф по X
  зажимается внутри той же зоны.

## Палитра (render)

Температура → 256-цветные коды `\x1b[38;5;Nm`, линейные интерполяции по
ступеням xterm-256: `0` → тёмный фон окна (234, если ячейка внутри камина);
затем тлеющий тёмно-красный край (160) → красный (196) → оранжевый
(202/214) → жёлтый (226) → горячее ядро белый (231). Искры рендерятся
поверх пламени яркими пикселями `✦` (в клетках рамки искры не рисуются).
Вне камина (рамка) — кирпичи `▓ █ ▒` в цветах 236–238, статично.
`render(state, width) → string` — ЧИСТАЯ функция: кадр одним строковым
блоком (курсор в начало `\x1b[H`, H строк, очистка хвоста `\x1b[J`); `width`
обрезает колонки на узких терминалах; тот же state → тот же кадр.
