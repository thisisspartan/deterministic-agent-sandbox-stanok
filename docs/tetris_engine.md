# tetris_engine — module contract (CC-282)

Pure, deterministic Tetris engine: no I/O, no time, no global mutable
state, no renderer/CLI imports. Every operation takes a `State` snapshot
and returns a **new** `State`; the input state is never mutated.

## Constants (pinned)

- `PIECES: dict[int, tuple]` — ids 1..7 = I, O, T, S, Z, J, L. Each value
  is a tuple of exactly 4 rotation states (matrices: tuples of tuples of
  0/1), generated by successive 90° clockwise rotations of the base shape;
  O's four states are identical. Every state occupies exactly 4 cells.
- `DEFAULT_WIDTH = 10`, `DEFAULT_HEIGHT = 20`.
- `SCORE_TABLE = {1: 100, 2: 300, 3: 500, 4: 800}` — points for clearing
  1..4 rows in one lock. `level = lines_cleared // 10 + 1`.
- `KICKS = (0, 1, -1, 2, -2)` — wall-kick x-offsets tried in this order
  on rotation.

## State

`State` — a frozen dataclass snapshot:

| field | meaning |
|---|---|
| `seed`, `rng_calls` | RNG state: the piece stream is one `random.Random(seed)`; `rng_calls` is how many pieces were drawn. The n-th piece is `Random(seed)` advanced n+1 times with `randrange(1, 8)` — reproducible and serializable. |
| `width`, `height` | board size |
| `board` | `list[list[int]]`, 0 empty, 1..7 locked piece id |
| `piece_id`, `piece`, `rot`, `x`, `y` | active piece: id, current matrix (`PIECES[piece_id][rot]`), board column/row of the matrix top-left cell |
| `score`, `lines_cleared`, `level` | scoring |
| `game_over` | set when a spawn collides with the board |

## Functions

- `new_game(seed, width=DEFAULT_WIDTH, height=DEFAULT_HEIGHT) -> State` —
  empty board, first piece spawned at the top center (`x = (width -
  matrix_width) // 2`, `y = 0`).
- `try_move(state, dx) -> State | None` — horizontal shift; `None` if the
  target collides with a wall, floor, or locked cells.
- `try_rotate(state, direction) -> State | None` — `direction` is +1/-1
  (index into `PIECES` modulo 4); tries every `KICKS` offset in order,
  first collision-free one wins; `None` if all are blocked.
- `soft_drop(state) -> State` / `tick(state) -> State` — one row down;
  if already resting, lock the piece into the board (cells = `piece_id`),
  clear full rows (remaining rows fall down, empty rows appear on top),
  update score/lines/level, spawn the next piece.
- `hard_drop(state) -> State` — drop to the lowest collision-free row,
  then the same lock/clear/spawn sequence.
- `is_game_over(state) -> bool` — True when the last spawn collided.

## Invariants

- All functions are pure: the input `State` (board, position, score) is
  unchanged by any call.
- After game over every operation is a no-op: it returns the same
  game-over state.
- A spawn collision (active cells overlapping locked cells or out of
  bounds) is the only game-over condition.
- Cleared rows are exactly the rows fully occupied after a lock (at most
  4, since a piece spans at most 4 rows).
