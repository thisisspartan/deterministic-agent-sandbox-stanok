# lerp — линейная интерполяция и clamp

Модуль `src/lerp.js` (CommonJS). Чистые детерминированные функции, без внешних
зависимостей и side effects.

## Экспорт

```js
const { clamp, lerp, invLerp } = require('./src/lerp.js');
```

## `clamp(v, lo, hi)`

Ограничивает `v` диапазоном `[lo, hi]`.

- Аргументы — числа (`v`, `lo`, `hi`).
- `TypeError` (с именем аргумента `"v"` / `"lo"` / `"hi"` в сообщении) — если
  аргумент не `number` или `NaN`.
- `RangeError` с сообщением `"lo > hi"` — если `lo > hi`.
- Примеры: `clamp(5, 0, 1)` → `1`; `clamp(-1, 0, 1)` → `0`;
  `clamp(0.5, 0, 1)` → `0.5`.

## `lerp(a, b, t)`

Линейная интерполяция: `a + (b - a) * t`.

- Аргументы — числа (`a`, `b`, `t`).
- `TypeError` (с именем аргумента `"a"` / `"b"` / `"t"` в сообщении) — если
  аргумент не `number` или `NaN`.
- `t` вне `[0, 1]` — НЕ ошибка: допустима экстраполяция
  (`lerp(0, 10, 1.5)` → `15`).
- Примеры: `lerp(0, 10, 0.5)` → `5`; `lerp(10, 0, 0.5)` → `5`.

## `invLerp(a, b, v)`

Обратная интерполяция: `(v - a) / (b - a)`.

- Аргументы — числа (`a`, `b`, `v`).
- `TypeError` (с именем аргумента `"a"` / `"b"` / `"v"` в сообщении) — если
  аргумент не `number` или `NaN`.
- `RangeError` с сообщением `"a === b"` — деление на ноль при `a === b`.
- `v` вне `[a, b]` — НЕ ошибка: экстраполяция допустима.
- Примеры: `invLerp(0, 10, 5)` → `0.5`; `invLerp(0, 10, 10)` → `1`.
