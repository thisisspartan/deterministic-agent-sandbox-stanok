# stats — статистика по числам

Модуль `src/stats.js` (CommonJS, `module.exports`). Чистые детерминированные
функции над массивами чисел: без внешних зависимостей, без `process`/`Date`,
без side effects. Входные массивы **не мутируются**.

## API

### `sum(a) → number`

Сумма элементов массива чисел. Пустой массив → `0`.

```js
sum([1, 2, 3])  // → 6
sum([])         // → 0
```

### `mean(a) → number`

Среднее арифметическое: `sum(a) / a.length`.

```js
mean([1, 2, 3, 4])  // → 2.5
```

### `median(a) → number`

Медиана: для нечётной длины — средний элемент отсортированного (по возрастанию)
массива; для чётной — среднее двух средних. Входной массив не мутируется
(сортируется копия).

```js
median([3, 1, 2])   // → 2
median([4, 1, 3, 2])  // → 2.5
```

### `variance(a) → number`

Дисперсия (популяционная): `sum((x - mean)^2) / a.length`.

```js
variance([2, 4, 4, 4, 5, 5, 7, 9])  // → 4
```

## Ошибки

| Ошибка | Условие | Сообщение |
|---|---|---|
| `TypeError` | аргумент `a` не массив | `"a"` входит в сообщение |
| `TypeError` | элемент неконечное число / `NaN` / `Infinity` | `"a[<i>]"` (индекс элемента) входит в сообщение |
| `RangeError` | `mean`: массив пуст | `"empty array"` |
| `RangeError` | `median`: массив пуст | `"empty array"` |
| `RangeError` | `variance`: элементов меньше двух (0 или 1) | `"need >= 2"` |

Валидация для всех четырёх функций: `a` обязан быть массивом
(`Array.isArray`), каждый элемент обязан быть конечным числом
(`typeof === 'number' && Number.isFinite`). `sum` принимает пустой массив
(возвращает `0`); `mean`/`median` — нет.
