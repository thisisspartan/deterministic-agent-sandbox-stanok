# slug — slugify (нормализация строк в URL-слаг)

Модуль `src/slug.js` (TASK-STANOK-CC-047).

## API

### `slugify(str, sep)`

- `str: string` — исходная строка. Если `str` не строка (`null`, `undefined`,
  число, …) — бросает `TypeError`.
- `sep: string` (опционально) — разделитель, строка длиной 1; по умолчанию `'-'`.
  Если `sep` передан, но не строка длиной 1 — бросает `TypeError`.
- Возвращает `string`. Пустая или только-мусорная строка → `''`.

```js
const { slugify } = require('./src/slug.js');

slugify('Hello World');          // 'hello-world'
slugify('  Trim   Me  ');        // 'trim-me'
slugify('a_b.c:d', '_');         // 'a_b_c_d'
slugify('a b', 'x');             // 'axb'
slugify('Привет Мир');           // '' (кириллица удаляется)
slugify('Café au lait');         // 'caf-au-lait' (акцент é удаляется)
```

## Правила

Порядок шагов:

1. **lowercase** — строка приводится к нижнему регистру (`toLowerCase`);
2. **пробелы → sep** — каждый пробел (`' '`, `\t`, `\n`, `\r`) заменяется на `sep`;
   любой другой ASCII-символ, не входящий в `[a-z0-9]` (`'.'`, `':'`, `'!'`, …),
   также заменяется на `sep`;
3. **удаление мусора** — все небуквенно-цифровые НЕ-ASCII символы (акценты,
   кириллица и т.п.) удаляются — они не транслитерируются; сохраняются только
   `[a-z0-9]` и сам `sep`;
4. **хлопание** — повторяющиеся `sep` схлопываются в один;
5. **обрезка** — `sep` обрезается в начале и в конце строки.

Результат — строка, состоящая из `[a-z0-9]` и одиночных `sep`; если символов
не осталось — `''`.
