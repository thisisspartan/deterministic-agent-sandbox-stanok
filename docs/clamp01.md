# clamp01 — clamp / lerp / invLerp

Чистые детерминированные числовые функции. CommonJS, внешних зависимостей нет.

## Экспорт

```js
const { clamp, lerp, invLerp } = require('./src/clamp01.js');
```

## Сигнатуры

### `clamp(v, lo, hi) → number`

Ограничивает `v` диапазоном `[lo, hi]`: `Math.min(hi, Math.max(lo, v))`.

```js
clamp(5, 0, 10);  // 5
clamp(-1, 0, 10); // 0
clamp(11, 0, 10); // 10
```

### `lerp(a, b, t) → number`

Линейная интерполяция: `a + (b - a) * t`.
`t` **не клампится** — экстраполяция за `[0, 1]` допустима.

```js
lerp(0, 10, 0.5); // 5
lerp(0, 10, 0);   // 0
lerp(0, 10, 2);   // 20 (экстраполяция)
```

### `invLerp(a, b, v) → number`

Обратная интерполяция: `(v - a) / (b - a)`. Экстраполяция допустима.

```js
invLerp(0, 10, 5);  // 0.5
invLerp(0, 10, 0);  // 0
invLerp(0, 10, 10); // 1
```

Свойство (для `a !== b`): `lerp(a, b, invLerp(a, b, v)) === v`.

## Семантика ошибок

- **`TypeError`** — любой аргумент не является конечным числом
  (`Number.isFinite` не проходит: строка, `NaN`, `Infinity`, `null` и т.п.).
  В сообщении указано имя аргумента: `"v"`, `"lo"`, `"hi"`, `"a"`, `"b"` или `"t"`.
  Проверка аргументов выполняется до остальных проверок.
- **`RangeError: "lo > hi"`** — `clamp` при `lo > hi`.
- **`RangeError: "a === b"`** — `invLerp` при `a === b` (деление на ноль).

## Инварианты

- Функции чистые и детерминированные: без `process`, `Date`, side effects.
- Границы диапазона возвращаются без изменений: `clamp(0, 0, 10) === 0`.
