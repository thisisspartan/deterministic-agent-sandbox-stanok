# rng — детерминированный сид-PRNG

Модуль `src/rng.js`: маленький чистый модуль без зависимостей — сид-генератор
(mulberry32) + три хелпера, позволяющие fire/fire3d воспроизводить один и тот
же паттерн (искры, угли, мерцание) при одном и том же seed и делать тесты
детерминированными.

## API

### `mulberry32(seed)` → `() => number`
Создаёт детерминированный генератор по алгоритму mulberry32. `seed` — любое
целое (нормализуется к uint32 через `seed >>> 0`). Возвращаемая функция `rng()`
без аргументов выдаёт float в `[0, 1)`. Один и тот же seed → идентичная
последовательность. Не использует `Math.random` или другие источники энтропии.

### `randInt(rng, min, max)` → `number`
Равномерное целое в `[min, max]` включительно. `min`/`max` — целые, `min <= max`;
иначе бросает `RangeError`. Результат — целое (`Number.isInteger(x) === true`).

### `pick(rng, arr)` → элемент
Равномерно случайный элемент массива `arr`. Если `arr.length === 0` —
бросает `RangeError`.

### `shuffle(rng, arr)` → `arr`
Fisher-Yates in-place перемешивание: мутирует `arr` на месте и возвращает тот же
объект (`shuffle(rng, a) === a`). Результат — перестановка исходного
мультимножества. Детерминирован при заданном `rng`. Длины 0 и 1 — порядок не
меняется.

## Детерминизм

Один seed → одна и та же последовательность значений, а значит и один и тот же
паттерн. Применение к fire/fire3d: при фиксированном seed анимация (искры,
угли, мерцание) воспроизводится идентично — можно «отыграть» и отладить
конкретный паттерн. Тесты модуля полностью детерминированы (`Math.random` не
используется нигде).

## Зависимости

Чистый Node.js, без внешних пакетов; из встроенных модулей ничего не
требует (только глобальные операторы и `Math.imul`).
