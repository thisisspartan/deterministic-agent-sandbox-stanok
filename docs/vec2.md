# vec2 — базовые операции 2D-векторов

Модуль `src/vec2.js` (CommonJS). Чистые детерминированные функции, без внешних
зависимостей и side effects.

## Экспорт

```js
const { length, normalize, add } = require('./src/vec2.js');
```

## `length(x, y)`

Длина вектора: `Math.hypot(x, y)`.

- Аргументы — числа (`x`, `y`).
- `TypeError` (с именем аргумента `"x"` / `"y"` в сообщении) — если аргумент не
  `number` или `NaN`.
- Пример: `length(3, 4)` → `5`.

## `normalize(x, y)`

Нормализованный вектор `{ x: x / L, y: y / L }`, где `L = Math.hypot(x, y)`.

- `Error` с сообщением `"normalize: zero vector"` — для нулевого вектора `(0, 0)`.
- `TypeError` — как в `length` (имя аргумента в сообщении).
- Пример: `normalize(3, 4)` → `{ x: 0.6, y: 0.8 }`.

## `add(a, b)`

Покомпонентное сложение: `{ x: a.x + b.x, y: a.y + b.y }`.

- `a`, `b` — объекты `{ x, y }` с числовыми полями.
- `TypeError` (с именем аргумента `"a"` / `"b"` в сообщении) — если аргумент не
  объект (или массив) или поле `x`/`y` не число/`NaN`.
- Функция чистая: аргументы не мутируются.
- Пример: `add({ x: 1, y: 2 }, { x: 3, y: 4 })` → `{ x: 4, y: 6 }`.
