# vec3 — векторные операции в 3D

Модуль `src/vec3.js` (CommonJS). Чистые детерминированные функции над
3D-векторами (объекты `{ x, y, z }` с числовыми компонентами), без внешних
зависимостей и side effects.

## Экспорт

```js
const { add, sub, scale, dot, cross, length, normalize } = require('./src/vec3.js');
```

## `add(a, b)`

Покомпонентное сложение: `{x: a.x + b.x, y: a.y + b.y, z: a.z + b.z}`.

- Пример: `add({x: 1, y: 2, z: 3}, {x: 4, y: 5, z: 6})` → `{x: 5, y: 7, z: 9}`.

## `sub(a, b)`

Покомпонентное вычитание: `{x: a.x - b.x, y: a.y - b.y, z: a.z - b.z}`.

- Пример: `sub({x: 5, y: 7, z: 9}, {x: 1, y: 2, z: 3})` → `{x: 4, y: 5, z: 6}`.

## `scale(v, s)`

Умножение на скаляр: `{x: v.x * s, y: v.y * s, z: v.z * s}`.

- `s` — число; нечисловой (включая `NaN`) — `TypeError` (имя `"s"` в сообщении).
- Пример: `scale({x: 1, y: 2, z: 3}, 2)` → `{x: 2, y: 4, z: 6}`.

## `dot(a, b)`

Скалярное произведение: `a.x * b.x + a.y * b.y + a.z * b.z`.

- Пример: `dot({x: 1, y: 0, z: 0}, {x: 0, y: 1, z: 0})` → `0`.

## `cross(a, b)`

Векторное (кросс) произведение:
`{x: a.y*b.z - a.z*b.y, y: a.z*b.x - a.x*b.z, z: a.x*b.y - a.y*b.x}`.

- Пример: `cross({x: 1, y: 0, z: 0}, {x: 0, y: 1, z: 0})` → `{x: 0, y: 0, z: 1}`.

## `length(v)`

Длина вектора: `Math.sqrt(v.x * v.x + v.y * v.y + v.z * v.z)`.

- Пример: `length({x: 3, y: 4, z: 0})` → `5`.

## `normalize(v)`

Приведение к единичной длине: `scale(v, 1 / length(v))`.

- `RangeError` с сообщением `"zero vector"` — для нулевого вектора.
- Пример: `normalize({x: 0, y: 0, z: 5})` → `{x: 0, y: 0, z: 1}`.

## Валидация аргументов (все функции)

- Вектор — объект с числовыми `x`, `y`, `z`. Не объект (включая `null`/массив) —
  `TypeError` с именем аргумента (`"a"` / `"b"` / `"v"`) в сообщении.
- Нечисловая (или `NaN`) компонента — `TypeError` с именем компоненты
  (`"x"` / `"y"` / `"z"`) в сообщении.
- Скаляр `s` — число; нечисловой — `TypeError` (имя `"s"` в сообщении).
- Все функции чистые: аргументы не мутируются.
