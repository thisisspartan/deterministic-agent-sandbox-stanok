# clamp — ограничение значений диапазонами

Модуль `src/clamp.js` (CommonJS, `module.exports`). Чистые детерминированные
функции: без внешних зависимостей, без `process`/`Date`, без side effects.

## API

### `clamp(v, min, max) → number`

Ограничивает число `v` диапазоном `[min, max]`:

- `v < min` → `min`;
- `v > max` → `max`;
- иначе → `v`.

```js
clamp(5, 0, 10)   // → 5
clamp(-3, 0, 10)  // → 0
clamp(42, 0, 10)  // → 10
```

### `clamp01(v) → number`

Частный случай: `clamp(v, 0, 1)`.

```js
clamp01(-1)   // → 0
clamp01(2)    // → 1
clamp01(0.5)  // → 0.5
```

### `clampVec(v, min, max) → {x, y}`

Покомпонентное ограничение 2D-вектора:
`{x: clamp(v.x, min.x, max.x), y: clamp(v.y, min.y, max.y)}`.
Возвращает новый объект, аргументы не мутируются.

```js
clampVec({x: -1, y: 5}, {x: 0, y: 0}, {x: 1, y: 1})  // → {x: 0, y: 1}
```

## Ошибки

| Ошибка | Условие | Сообщение |
|---|---|---|
| `RangeError` | `min > max` (в `clampVec` — для любой компоненты) | `"min > max"` |
| `TypeError` | `v`, `min` или `max` не число (включая `NaN`) | имя аргумента (`"v"` / `"min"` / `"max"`) входит в сообщение |
| `TypeError` | `clampVec`: аргумент не объект с числовыми `x`, `y` (включая `NaN`-компоненту) | имя аргумента / компоненты (`"x"` / `"y"`) входит в сообщение |

Проверка типов: `typeof value === 'number' && !Number.isNaN(value)`;
для векторов — каждый аргумент должен быть объектом (не `null`, не массив)
с числовыми полями `x` и `y`.
